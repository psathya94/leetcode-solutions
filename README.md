# LeetCode Solutions

A collection of solutions to LeetCode and related coding interview problems.

## Repository Structure

Each solution is stored as a separate file named with the problem number and title:

```text
<number>. <problem title>
```

Examples:

- `1. Two Sum`
- `15. 3Sum`
- `206. Reverse Linked List`

## Topics Covered

- Arrays and strings
- Linked lists
- Stacks and queues
- Trees and graphs
- Dynamic programming
- Backtracking
- Searching and sorting
- Hash tables

## How to Use

Browse the files to review individual solutions. Each file contains the implementation for its corresponding problem and can be adapted to the language or platform required by the problem.

## Progress

Solutions are added over time as problems are solved and revisited.
